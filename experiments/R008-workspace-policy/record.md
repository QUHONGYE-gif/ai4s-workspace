## Agent 与模拟检查

真实 DeepSeek 对普通问答未生成提案，策略版本未变。首次回复对“跳过候选复用”的描述容易被理解成删除旧结果。修正提示后复问，回复明确旧结果继续保留，强制重算保留原种子，新采样更换种子。

在网页输入「请把默认复用方式改成允许复用」，Agent 展示「强制重算 → 允许复用」时仍为版本 3。点击确认后产生版本 4，修改记录显示来源为「助手提案」。独立测试数据中的此操作也恢复了默认「允许复用」。

搬运阈值、空间上限、保留策略用固定示例验证。6 秒的搬运时间超过 5 秒阈值，模拟选择重算。10 MB 示例数据受 7 MB 预算约束，LRU 模拟先淘汰 A，成本分数示例先淘汰 B。单元测试覆盖规则，浏览器验证手动预览、取消、确认和撤回。

Python 回归 112 项通过，21 项跳过。6 个 JavaScript 测试文件通过。真实运行验证使用以上单任务与缓存对照。新采样的既有引擎证据见 [R006](../R006-aiida-engine/record.md)，本轮尚未在面板上重跑该路径。
