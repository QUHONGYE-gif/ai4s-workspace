# UI 功能检查

检查日期：2026-10-30。对照本地 UI 改版前的 `eb808d1^`、动画改版前的 `5d6ffea`，以及从 GitHub 重新拉取核实的 [`dev-ckz` / `0089e6f`](https://github.com/QUHONGYE-gif/ai4s-workspace/tree/0089e6f)。

## 发现与修复

| 检查项 | 发现的问题 | 当前处理 |
| --- | --- | --- |
| 节点详情 | 页面自动选择第一步，未点击也展示详情 | 创建页和实验页默认隐藏；点击节点后在流程图下方打开，可关闭，切换页面重置选择 |
| 实验流程图布局 | 配置和结果上下各显示一张图 | 改为同一容器内切换；配置底部进入结果，再开始模拟。切换不启动／重置实验，候选和进度保留，刷新恢复所选视图 |
| 创建页候选与理由 | 侧栏未传入步骤计划，无法在创建页查看理由、候选与手动执行方式 | 将当前步骤计划传给详情；保留自动、重算、复用、等待的选择 |
| 计划导出与总览 | 导出处理函数仍在，但 UI 入口和创建页成本总览遗漏 | 恢复到「计划摘要与导出」，显示总用时及复用／等待／重算数量 |
| 失败模拟 | 后端逻辑仍在，但选择入口遗漏 | 在「共享与运行选项」恢复成功／失败选择；不恢复已要求删除的体验场景栏 |
| 随机种子 | 自定义流程没有节点参数定义，改版后失去编辑入口 | 在共享与运行选项中补充随机种子，已有节点级种子的流程不重复展示 |
| 候选刷新 | 文本／数字参数提交后只保存，画面仍显示旧候选 | 提交参数后刷新计划和候选，验证种子变化后可选择相应共享任务 |
| 结果身份与步骤成本 | 原节点弹窗中的结果身份、原计划表中的读取／计算成本缺少入口 | 保留在步骤详情的说明和计划中 |
| 产物所属人与可读性 | 列表换成图后所属人及文件可读状态不直观 | 图下增加折叠产物清单，保留所属人、ID、生成方式、可读状态及详情／工具入口 |
| 历史依赖名称 | 节点详情依赖全局当前工作流，而非该实验快照 | 从实验保存的步骤快照读取名称，防止后续流程编辑改变历史解释 |

## 保留与有意调整

- 输入来源保留：内置示例、已有产物、登记路径和本地文件信息。
- 模型／数据库／预测器及种子参数转入节点详情；实验意图、共享范围、复用策略、读取位置保留在折叠选项中。
- 创建与启动分开：创建保存 `ready` 实验，详情页确认候选后运行。检查候选由当前输入自动计算，修改参数后重新计算，不依赖原来的长页面检查按钮。
- 模拟执行、取消、部分产物保留、复制配置、快照导出、浏览器备份、服务端修订冲突保护均保留。身份计算、候选匹配、保留策略及模拟执行核心函数与改版前相同。
- 产物来源、所属人、共享状态、固定保存、再次用作输入、结构工具入口均保留。页面结构与导航调整不替代真实模型执行。
- 按原需求删除体验场景快捷栏；预置示例不计入「我的实验」，团队示例入口继续保留。

## 参考分支的独立更新

本地与 `dev-ckz` 的共同祖先为 `eca7a7d`。参考分支后续的 `4c77ef3` 添加嵌入式 AI 辅助接入与表单回填，`194a0d5` 添加端口感知画布、结构化图操作和对应 API，`0089e6f` 修复回边布局。这些提交未合入本地分支，不是本次 UI／动画改版删除的功能。

本地保留原有独立「智能体接入」入口。本次修复不整批替换 Agent 前后端，也未调用付费模型 API。不能据此声称本地已具备参考分支的全部最新 AI 功能。
