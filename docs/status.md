# 当前状态

## 已具备

- 工作台演示页面覆盖工作流、实验、候选产物、模拟运行及来源查看；Python API 保存按浏览器命名空间隔离、带修订冲突检查的模拟快照。
- 创建实验页改为「一张流程图 + 按需节点详情」：去掉体验场景入口，详情默认隐藏，点击步骤后查看输入与输出、参数（字段取自 [演示配置](../configs/workbench-demo.json) 的步骤定义）、复用原因、身份和候选，可关闭；创建实验只保存待确认的计划，进入实验详情后点「确认候选并开始模拟」才运行。计划导出与失败模拟保留在折叠选项中，结果图下可展开产物所属人与文件可读状态。功能对照见 [UI 功能检查](ui_function_audit.md)。
- 工作流预览与实验产物区采用参考 [live-panel](https://github.com/ythx-101/live-panel-skill) 的浅色阶段卡片和箭头连线；连线来自步骤依赖，配有流动数据点、卡片呼吸和图标跳动。预览标注流程示意，完成后标注流向回放，运行中按模拟状态显示当前步骤；失败、取消或中断后停止流动。支持暂停／播放动效（默认尊重系统减少动态效果设置），保留节点详情和产物／结构工具入口，窄屏可横向查看整条流程。
- 实验详情使用单个流程图容器，在「配置视图」和「运行与结果」间原位切换。待运行实验默认显示配置，底部按钮进入结果视图后可开始模拟；已有运行记录默认显示结果。切换保留候选、节点选择和执行进度，视图选择随 URL 保存，结果视图承载进度条、产物清单和原有状态动效。
- PyMOL 已接入已有工具页面，支持真实 PDB/mmCIF 上传、显示方式切换、网页命令、历史和可折叠输出；简洁视图与完整原生界面共用同一会话。
- 独立蛋白质设计程序提供 RFdiffusion → ProteinMPNN → 可选 MMseqs2 → Boltz-2 的配置与执行入口。
- Docker + Coder 模板及成员管理入口用于个人开发与预览。

- 个人分支保留 R001–R004 的真实租用 GPU 实验记录及证据；历史 CPU 搜索封装与独立 GPU 搜索分支已实跑。现有重构版本与历史执行快照分别判断，见 [流程记录](protein_pipeline.md)。

- Agent 接入 Demo 已实现三模型参数配置、资料识别、真实 DeepSeek 工具调用、登记与请求生成；本机历史 API 验收见 [运行记录](agent_demo_run.md)。已接入工作台导航与相对路径预览，并同步到个人 Coder；目标环境 37 项 Python 检查、浏览器改参与刷新持久化通过。本次分支合并后，Coder 页面显示 DeepSeek 已配置；未重新调用付费 API。画布分支已合入并完成真实预览检查，详见运行说明。

## 限制

- 工作流执行、科学产物目录、多人共享和复用策略仍为模拟；浏览器命名空间不等于真实成员鉴权。
- 蛋白质程序尚未与工作台 API 联通，当前版本没有目标环境端到端 GPU 验收或科研效果结论。
- 自动 CI/CD 与正式产品部署尚未接入。
