# 研序图片素材

| 用途 | 文件 | 页面位置 |
| --- | --- | --- |
| 流程封面 | [蛋白质](protein-workflow.webp) · [小分子](molecule-workflow.webp) · [自定义](custom-workflow.webp) | 工作流卡片 |
| 空状态 | [没有实验](empty-experiments.webp) · [没有搜索结果](empty-search.webp) · [流程无步骤](empty-canvas.webp) | 实验表、数据目录、流程图 |

| 介绍页 | [首屏](landing-hero.webp) · [团队共享](landing-network.webp) · [入口](landing-login.webp) | 项目介绍页首屏、主张段落、成员入口 |
